# Projek Aplikasi Modular

Platform aplikasi modular dengan teras bersama dan modul perniagaan yang boleh dipasang, dikembangkan dan diurus secara berasingan.

## Current Development Scope

Fasa semasa memberi fokus kepada pembangunan Core.

### Fasa 1 — Core Basic Foundation

- Account
- Authentication
- Profile
- Session
- Account Status
- Super Admin

Business Module belum dibangunkan dalam fasa ini.

## Development Order

1. Backend / Core API
2. Backend Testing & Review
3. Flutter User App
4. Web App

## Tech Stack

### Backend
- Laravel 13
- PHP 8.3
- MySQL 8.x

### User App
- Flutter
